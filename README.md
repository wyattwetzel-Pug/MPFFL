# MPFFL

The league management site for the MPFFL — a 16-team keeper league with an
August auction, three-year contracts, a salary cap, rookie drafts, toppers,
holdovers, and a transaction ledger that never forgets.

Forked with love from the parent league's engine, August 2026. From here it
is yours: your data, your rules, your code.

Start with [SETUP.md](SETUP.md) to launch it. Read
[ARCHITECTURE.md](ARCHITECTURE.md) to understand the one big idea the site
is built on. Read [WORKING-AGREEMENT.md](WORKING-AGREEMENT.md) to learn how
to build on it with an AI agent without wrecking it.
