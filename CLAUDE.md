# MPFFL

League management site for the MPFFL, a 16-team keeper league. Forked from
a parent league's engine in August 2026; this repo is standalone.

Read before working — these are canonical:

@AGENTS.md
@WORKING-AGREEMENT.md
@ARCHITECTURE.md
@OPERATIONS.md

`PLAN.md` is the living roadmap and decision log — check it before
starting work, and record decisions there as they're made. `SETUP.md` is
the launch runbook.
